# Abhi Gupta — Digital Identity Website

Responsive static profile website with emerald-green styling, built in one `index.html` file using HTML, CSS, and vanilla JavaScript.

## Deploy on Vercel
1. Extract the ZIP.
2. Upload `index.html` to a GitHub repository root.
3. Import that repository in Vercel.
4. Choose Framework Preset **Other**. Leave Build Command and Output Directory empty.
5. Deploy and test the `.vercel.app` URL.

## NFC sticker
Once deployed, open NFC Tools → Write → Add a record → URL/URI, paste the full HTTPS website URL, then choose Write and tap the sticker with an NFC-capable phone.

The sticker stores the website URL, not the website itself. Keep hosting active.

## Before sharing
Check that phone, email, LinkedIn, and Instagram links are correct. No photo, CV download, or unprovided achievements were added. Skills/strengths are framed as interests and learning areas.
